# Solmar Bay

An original sunset-soaked coastal crime game. Play as Rook, a driver working jobs for fixer Mara Voss across Marina, Old Town, Palm Boulevard and Harbor Heights. Steal cars, deliver a hot package, evade the bay patrol and find the crew's hideout. Story progress and cash save locally.

## Controls

- WASD: move on foot or drive
- Shift: run; Space: jump
- E: steal a nearby car or get out
- Drag the mouse: orbit the camera; click: fire the pistol
- Esc or P: pause; M: mute

## Run

Run `node serve.ts`, then open http://localhost:8080.
